# Assignment 1 Sale Price Data ML Workflow

## Getting Started

This project is built and managed with [uv](https://docs.astral.sh/uv/).

### Option 1: Using `uv` (recommended)

Install dependencies and start JupyterLab:

```bash
uv sync
uv run jupyter lab
```

### Option 2: Using a virtual environment

Create and activate a virtual environment, install the project, and start JupyterLab:

```bash
python -m venv .venv
source .venv/bin/activate
pip install .
jupyter lab
```

> **Note:** The virtual environment activation command above is for macOS/Linux. On Windows, use `.venv\Scripts\activate` instead.
